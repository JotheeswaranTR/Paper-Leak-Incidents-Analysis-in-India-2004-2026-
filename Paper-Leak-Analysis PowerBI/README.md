# 📊 Paper Leak Incidents Analysis in India (2004–2026)

An interactive **Power BI dashboard** that analyzes paper leak incidents across India between **2004 and 2026**. The project transforms raw incident data into meaningful insights through executive-level reporting, geographic analysis, and enforcement metrics.

---

## 📌 Project Overview

This dashboard was built to explore:

- Trends in paper leak incidents over time
- Geographic distribution across Indian states
- Performance of conducting bodies
- Investigation and enforcement outcomes
- Data transparency and confidence

The objective was to create a dashboard that not only visualizes data but also tells a clear story for decision-makers.

## 📈 Key Insights

- 📌 **110** paper leak incidents reported between **2004–2026**
- 🗺️ **25** states affected
- ✔️ **81%** of reported incidents were confirmed
- ⚖️ **69.7%** arrest rate
- 🚨 **91% conviction gap**
- 🏛️ **80%** of incidents involved State conducting bodies
- 📊 Dataset confidence: **74%**
